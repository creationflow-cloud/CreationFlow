WooCommerce adapter skeleton for connecting a shop to a self-hosted CreationFlow server.

== Description ==

CreationFlow WooCommerce is an adapter plugin skeleton. It stores basic connection settings for a future self-hosted CreationFlow API integration.

This plugin does not implement editor logic, renderer logic, pricing logic, license validation, or real API communication.

== Installation ==

1. Upload the `creationflow-woocommerce` folder to `/wp-content/plugins/`.
2. Activate `CreationFlow WooCommerce` in WordPress.
3. Open Settings > CreationFlow.
4. Enter placeholder connection settings if needed.

== Frequently Asked Questions ==

= Does this plugin connect to CreationFlow yet? =

No. The real API connection will be added later.

= Does this plugin validate licenses? =

No. License validation is intentionally outside this public adapter skeleton.
