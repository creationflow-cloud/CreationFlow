# @creationflow/core

Core document operations for CreationFlow.

## Exports

### Document Creation

- `createEmptyDocument()` — create a new empty document with metadata
- `createConfigurationDocument()` — create a configuration document from a template

### Element Operations

- `addElement()` — add an element to a surface
- `updateElement()` — update element properties in a document

### Layer Operations

- `getElementZIndex()` — get the zIndex of an element
- Layer reordering functions for bring forward/backward, to front/back

### Page/Surface Operations

- Page and surface helper functions

## Dependencies

- `@creationflow/schema` — type definitions
