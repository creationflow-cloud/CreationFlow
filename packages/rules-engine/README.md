# @creationflow/rules-engine

Rule evaluation engine for CreationFlow.

## Exports

- `evaluateRules()` — evaluate rules against a document context

## Types

- `RuleEvaluationResult` — result of rule evaluation
- `RuleContext` — context for rule evaluation

## Current Status

This package is a placeholder. The `evaluateRules()` function exists but is minimal and not yet integrated into the document workflow.
